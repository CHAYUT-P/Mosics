# Mosics

แอปฟังเพลงขนาดเล็กมาก เล่นเฉพาะเสียงเพลง หน้าตาแบบแผ่นเสียงไวนิล ค้นหาเพลงจากคลังของ YouTube Music แต่เล่นแค่เสียง ไม่มีวิดีโอ ไม่มีโฆษณา และใช้หน่วยความจำน้อยกว่า Spotify หลายเท่า

Mosics บน Mac และบน Windows เป็น **แอปเดียวกัน เวอร์ชันเดียวกัน** (ดูไฟล์ [`VERSION`](VERSION)) ดีไซน์เหมือนกัน ฟีเจอร์เหมือนกัน และใช้ไฟล์คลังเพลงรูปแบบเดียวกัน

- **Mac:** เขียนด้วย Swift + SwiftUI ขนาดประมาณ 2.5 MB
- **Windows:** เขียนด้วย C++ + Win32 ขนาดประมาณ 570 KB

## ทำอะไรได้บ้าง

- ค้นหาเพลง หรือสลับไปที่ **Videos** เพื่อหาเวอร์ชันไลฟ์ เพลงคัฟเวอร์ และคลิปที่คนอัปโหลด เลื่อนลงเพื่อโหลดผลลัพธ์เพิ่ม
- **หน้า Home:** เพลงที่กำลังเล่น มิกซ์ที่จัดมาให้ (Thai Indie, City Pop, Japan Indie & Anime, If You Like Oasis และมิกซ์จากเพลงที่คุณฟังบ่อย) และแผ่นเสียงที่เพิ่งฟัง
- **เพลย์ลิสต์** ตั้งปกเองได้: เลือกลายปกแผ่นเสียง ใช้ปกอัลบั้มของเพลงในเพลย์ลิสต์ หรือเลือกรูปจากเครื่อง
- เพลงที่ถูกใจ (Liked Songs), เพลงที่เพิ่งเล่น, คิวเพลง, สุ่มเพลง, เล่นซ้ำ และ **เล่นเพลงคล้ายกันต่ออัตโนมัติ** เมื่อคิวหมด
- **โหมดเบื้องหลัง:** ปิดหน้าต่างแล้วเพลงยังเล่นต่อ ควบคุมได้จากไอคอนแผ่นเสียงที่แถบเมนูด้านบน (Mac) หรือที่ถาดไอคอนมุมขวาล่าง (Windows)
- ใช้ปุ่มควบคุมเพลงบนคีย์บอร์ดได้ทั้งสองระบบ

## เบาแค่ไหน

วัดบน Mac ขณะกำลังเล่นเพลง:

| | Mosics | Spotify |
|---|---|---|
| หน่วยความจำ (เปิดหน้าต่าง) | **~72 MB** | ~950 MB |
| หน่วยความจำ (ปิดหน้าต่าง) | **~62 MB** | — |
| CPU | **0.3–2%** | ~11% |

## วิธีติดตั้งบน Windows

ต้องใช้ Windows 10 (เวอร์ชัน 1803 ขึ้นไป) หรือ Windows 11

1. ดาวน์โหลด **`Mosics.exe`** จากหน้า [Releases](https://github.com/CHAYUT-P/Mosics/releases)
2. เปิดไฟล์ ถ้า Windows SmartScreen ขึ้นว่า "Windows protected your PC" ให้กด **More info → Run anyway** (เพราะแอปนี้ไม่ได้ลงนามดิจิทัล)
3. กด **Set up Mosics** แค่นั้นเสร็จเลย ปุ่มเดียวจะ:
   - ติดตั้ง Mosics ให้บัญชีของคุณ (ไม่ต้องใช้สิทธิ์ admin) พร้อมทางลัดใน **Start menu** และบน **เดสก์ท็อป**
   - ดาวน์โหลดโปรแกรมฟรีสองตัวที่ใช้เล่นเพลง คือ **yt-dlp** และ **Deno** (ประมาณ 60 MB ครั้งเดียว)

หลังติดตั้งแล้วลบไฟล์ `Mosics.exe` ที่ดาวน์โหลดมาทิ้งได้ เวลาจะอัปเดต ให้ดาวน์โหลด `Mosics.exe` ตัวใหม่แล้วเปิด ระบบจะติดตั้งเวอร์ชันใหม่ทับให้เอง
ถ้าจะลบ Mosics: **Settings → Apps → Installed apps → Mosics → Uninstall**

**คีย์ลัด:** Space เล่น/หยุด · Ctrl+→ / Ctrl+← เพลงถัดไป/ก่อนหน้า · Ctrl+↑ / Ctrl+↓ เสียงดัง/เบา · Ctrl+S สุ่มเพลง · Ctrl+R เล่นซ้ำ · Ctrl+L ถูกใจเพลงนี้ · Ctrl+F ค้นหา · Esc ปิดหน้า Now Playing

คลังเพลงเก็บไว้ที่ `%APPDATA%\Mosics\` และเพลงที่เคยเล่นจะถูกเก็บแคชไว้ที่ `%LOCALAPPDATA%\Mosics\cache` (ไม่เกิน 400 MB)

## วิธีติดตั้งบน Mac

ต้องใช้ macOS 14 (Sonoma) ขึ้นไป

1. **ติดตั้ง yt-dlp** (Mosics ใช้โปรแกรมนี้ดึงเสียงเพลง) ผ่าน [Homebrew](https://brew.sh):
   ```bash
   brew install yt-dlp
   ```
   คำสั่งนี้จะติดตั้ง `deno` ที่ yt-dlp ต้องใช้กับ YouTube ให้ด้วย
2. **ติดตั้งแอป** เลือกวิธีใดวิธีหนึ่ง:
   - ดาวน์โหลด `Mosics-mac.zip` จากหน้า [Releases](https://github.com/CHAYUT-P/Mosics/releases) แตกไฟล์ แล้วลาก **Mosics** ไปไว้ใน **Applications** หรือ
   - build เองจากโค้ด (ต้องมี Xcode หรือ Command Line Tools):
     ```bash
     cd mac
     ./build.sh --install
     ```
3. **เปิดครั้งแรก:** แอปนี้ไม่ได้ลงนามกับ Apple ระบบอาจขึ้นว่า "เปิดไม่ได้" ให้ไปที่ **System Settings → Privacy & Security** เลื่อนลงแล้วกด **Open Anyway** (หรือพิมพ์คำสั่ง `xattr -dr com.apple.quarantine /Applications/Mosics.app` ครั้งเดียว)

**คีย์ลัด:** Space เล่น/หยุด · ⌘→ / ⌘← เพลงถัดไป/ก่อนหน้า · ⌘↑ / ⌘↓ เสียงดัง/เบา · ⌥⌘S สุ่มเพลง · ⌘R เล่นซ้ำ · ⌘L ถูกใจเพลงนี้ · Esc ปิดหน้า Now Playing

คลังเพลงของคุณเก็บไว้ที่ `~/Library/Application Support/Mosics/`

## ย้ายคลังเพลงระหว่าง Mac กับ PC

ทั้งสองแอปเก็บเพลงที่ถูกใจ เพลย์ลิสต์ และประวัติการฟังในไฟล์ `library.json` รูปแบบเดียวกัน คัดลอกไฟล์ไปอีกเครื่องแล้วเปิด Mosics ใหม่ได้เลย:

- Mac: `~/Library/Application Support/Mosics/library.json`
- Windows: `%APPDATA%\Mosics\library.json`

(ถ้าตั้งปกเพลย์ลิสต์จากรูปของคุณเอง รูปจะอยู่ในโฟลเดอร์ `covers` ข้าง ๆ ไฟล์นี้ ให้คัดลอกไปด้วย)

## ทำงานอย่างไร

- **การค้นหา มิกซ์ และเพลงแนะนำ** ดึงจาก API สาธารณะของ YouTube Music โดยตรง ไม่ต้องมีบัญชีหรือคีย์
- **เสียงเพลง** ดึงผ่าน [yt-dlp](https://github.com/yt-dlp/yt-dlp) ซึ่งผ่านระบบกันบอทของ YouTube ได้ และโหลดเฉพาะเสียงเท่านั้น บน Windows แอปจะอัปเดต yt-dlp ให้เอง ส่วนบน Mac ถ้าวันหนึ่งเพลงเล่นไม่ได้ ให้สั่ง `brew upgrade yt-dlp`
- แผ่นเสียง ร่องแผ่น และปกแผ่นทั้งหมดวาดด้วยโค้ด จึงไม่ทำให้แอปใหญ่ขึ้น

## การ build และออกเวอร์ชันใหม่

```
VERSION     เลขเวอร์ชันของทั้งสองแอป (เลขเดียวใช้ทั้ง Mac และ Windows)
mac/        แอป SwiftUI — build.sh สร้าง dist/Mosics.app
windows/    แอป Win32 — build.sh สร้าง dist/Mosics.exe (brew install mingw-w64)
```

ทุกครั้งที่ push ขึ้น GitHub ระบบ GitHub Actions จะ build ทั้งสองแอป และทดสอบแอป Windows บนเครื่อง Windows จริง (มีภาพหน้าจอเก็บไว้ในแต่ละรอบ) ถ้าจะออกเวอร์ชันใหม่ ให้แก้เลขใน `VERSION` แล้ว commit จากนั้น push tag ที่ตรงกัน:

```bash
git tag v1.1.0
git push origin v1.1.0
```
